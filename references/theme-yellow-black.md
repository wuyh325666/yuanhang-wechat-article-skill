# 远航收藏夹黑黄主题

## 设计变量

| 变量 | 色值 | 用途 |
|---|---:|---|
| 主色 Yellow | `#ffda51` | 提醒、标签、局部视觉锚点 |
| 结构黑 Ink | `#111827` | 标题、左边框、核心判断、深色信息块 |
| 正文灰 Body | `#2f3742` | 正文长阅读 |
| 辅助灰 Muted | `#64748b` | 图片说明、补充信息 |
| 边框灰 Line | `#979899` | 图片、卡片、分隔 |
| 浅底 Soft | `#fff8d9` | 提醒卡、局部浅黄底 |
| 代码底 Code | `#f8fafc` | 代码块、提示块 |

## 主题气质

用于“远航收藏夹”的 AI 工具、知识管理、工作流、产品观察类文章。整体应是白底、黑字、黄点睛，不做大面积黄色铺底；信息密度偏高，但段落要有呼吸感。

黑色负责结构和判断，黄色负责提醒和扫读。默认不把加粗和标黄叠加使用。

## Markdown 语义映射

| Markdown | 语义 | 视觉 |
|---|---|---|
| `# 标题` | 微信标题字段 | 默认不进入正文 |
| `## 标题` | 一级板块 | 黑色左竖条小标题 |
| `### 标题` | 小节 | 黑字加粗小标题 |
| `**文字**` | 观点判断、定义、核心转折 | 只加粗，不标黄 |
| `==文字==` | 提醒、坑点、操作建议 | 只标黄，不加粗 |
| `` `code` `` | 行内代码、工具名 | 浅灰底等宽 |
| `> 引用` | 引用/编者按/提示 | 左黑线浅黄底引用块 |
| `![说明](path)` | 正文配图 | 白底、细边框、居中、灰色说明 |
| 围栏代码块 | Prompt/命令/代码 | 浅灰底、左黄条、等宽 |
| 列表 | 要点或步骤 | 紧凑缩进，黑色圆点/编号 |

## 排版组件规范

### 正文

- 字号 `15px`
- 行高 `1.95`
- 颜色 `#2f3742`
- 段落间距 `18px`
- 文本两端对齐
- 不要把每句话都单独成段，短句只用于强调和转场

### 板块标题

- 使用 `section` 包裹
- 左边框 `4px solid #111827`
- 左内边距 `12px`
- 顶部间距 `36px`
- 标题字号 `21px`
- 标题颜色 `#111827`

### 加粗与标黄

- 加粗用于观点判断、定义、概念转折
- 标黄用于提醒用户留心、注意坑点、马上可执行的建议
- 默认不叠加
- 尽量嵌入段落中段，避免总放在板块开头或末尾
- 每个板块可以有一个视觉锚点，但不是必须机械铺满

### 图片

- 图片宽度 `100%`
- 白底
- 边框 `1px solid #979899`
- 内边距 `4px`
- 无圆角
- caption 字号 `13px`
- caption 颜色 `#64748b`
- 图片放在关键观点或操作说明之后，不堆在结尾

### 引用/提示

用于编者按、口径提醒、注意事项。视觉上用浅黄底和左黑线，不使用四周虚线框。

### 代码块

用于命令、Prompt、配置。浅灰底，左侧黄条，避免深色代码块在公众号里压迫感过强。

## 文章类型配方

| 类型 | 推荐组件组合 |
|---|---|
| 发布会/产品更新解读 | 开头判断段 → 信息图 → 左竖条章节 → 加粗观点 → 标黄提醒 → 结尾判断 |
| 工具教程 | 价值判断 → 步骤标题 → 代码块/Prompt → 截图 → 检查清单 |
| 视频转公众号 | 场景开头 → 观点重写 → 步骤/案例 → 截图配图 → 可执行总结 |
| 知识库/方法论 | 痛点纠偏 → 框架图 → 操作步骤 → 示例 Prompt → 复盘建议 |
| 案例复盘 | 背景 → 过程 → 关键节点图 → 可复用方法 → 结论 |

## 质量检查

- 小标题使用黑色左竖条
- 加粗和标黄语义分开
- 强调不集中在板块第一段或最后一段
- 图片有 caption，且 caption 不标黄
- 全文黄色情绪克制，只做锚点
- HTML 全部使用内联样式
